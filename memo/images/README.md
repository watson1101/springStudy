# 图标说明

请在此目录下添加以下TabBar图标文件（建议尺寸：81x81px）：

## 必需的图标文件

1. **tab-memo.png** - 备忘页面图标（未选中状态）
2. **tab-memo-active.png** - 备忘页面图标（选中状态）
3. **tab-setting.png** - 设置页面图标（未选中状态）
4. **tab-setting-active.png** - 设置页面图标（选中状态）

## 图标要求

- 尺寸：建议 81x81 像素
- 格式：PNG
- 大小：不超过 40KB
- 颜色：
  - 未选中：灰色系（#999999）
  - 选中：蓝色系（#1890ff）

## 临时解决方案

如果暂时没有图标，可以：

1. 从 iconfont 等图标库下载
2. 使用在线工具生成
3. 修改 app.json 移除 tabBar 配置

## 推荐图标来源

- [Iconfont](https://www.iconfont.cn/)
- [IconPark](https://iconpark.oceanengine.com/)
- [微信小程序官方图标库](https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html)
