# 智能备忘微信小程序

一个基于AI的智能备忘录小程序，支持文字输入、图片上传，并能智能识别提醒时间。

## 功能特点

- **快速记录**: 打开即输入，支持文字和图片
- **AI智能识别**: 支持调用Kimi、DeepSeek、GLM等大模型智能识别提醒时间
- **定时提醒**: 到时间后自动发送微信消息提醒
- **分类管理**: 自动对备忘进行分类
- **本地存储**: 数据保存在本地，无需服务器

## 使用说明

### 1. 准备工作

#### 1.1 获取AI API密钥（可选）

支持以下AI提供商，需要获取相应的API密钥：

- **Kimi (月之暗面)**: https://platform.moonshot.cn
- **DeepSeek**: https://platform.deepseek.com
- **智谱GLM**: https://open.bigmodel.cn

#### 1.2 配置订阅消息（可选）

如需微信消息提醒功能，需要：

1. 登录微信公众平台
2. 进入"功能" -> "订阅消息"
3. 选择或创建消息模板
4. 获取模板ID

### 2. 小程序配置

#### 2.1 添加TabBar图标

在 `images/` 目录下添加以下图标文件（建议尺寸：81x81px）：

- `tab-memo.png` - 备忘图标
- `tab-memo-active.png` - 备忘选中图标
- `tab-setting.png` - 设置图标
- `tab-setting-active.png` - 设置选中图标

#### 2.2 修改appid

打开 `project.config.json`，将 `appid` 改为你自己的小程序appid：

```json
"appid": "你的小程序appid"
```

### 3. 运行小程序

1. 使用微信开发者工具打开本项目
2. 在设置页配置AI API密钥（可选）
3. 开始使用！

## 主要功能说明

### AI智能识别

配置AI API后，小程序会自动分析输入的文本，识别：

- **标题**: 自动提取或生成简洁标题
- **提醒时间**: 识别"明天下午3点"、"2小时后"等时间表达
- **分类**: 自动分类为工作/生活/学习/其他

### 本地解析

未配置AI时，使用本地规则解析，支持识别：
- X分钟后/小时后
- 明天/后天
- 具体时间（如：15:30）
- 日期（如：5月20日）

### 提醒功能

- 到达提醒时间后，小程序打开时会弹出提醒
- 如配置了订阅消息，会收到微信服务通知

## 开发说明

### 技术栈

- 微信小程序原生框架
- 本地存储（localStorage）

### API调用

AI调用在 `utils/ai.js` 中实现，支持：
- Kimi API (moonshot-v1-8k)
- DeepSeek API (deepseek-chat)
- 智谱GLM API (glm-4-flash)

## 注意事项

1. **API密钥安全**: 请勿将API密钥泄露给他人
2. **订阅消息**: 需要用户主动授权才能发送
3. **本地存储**: 更换设备或清除缓存会丢失数据
4. **图片存储**: 图片目前使用临时路径，重启后可能失效
