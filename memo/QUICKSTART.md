# 快速开始指南

## 第一步：准备图标

由于微信小程序的TabBar需要图标文件，请先准备以下图标：

**在 `images/` 目录下添加：**
- `tab-memo.png` - 备忘图标（81x81px，灰色）
- `tab-memo-active.png` - 备忘选中图标（81x81px，蓝色）
- `tab-setting.png` - 设置图标（81x81px，灰色）
- `tab-setting-active.png` - 设置选中图标（81x81px，蓝色）

**没有图标？** 暂时可以先删除 `app.json` 中的 `tabBar` 配置项来运行。

## 第二步：配置小程序

1. **修改appid**
   - 打开 `project.config.json`
   - 将 `"appid": "touristappid"` 改为你自己的小程序appid

2. **在微信开发者工具中打开**
   - 打开微信开发者工具
   - 选择"导入项目"
   - 选择本目录
   - 填写appid

## 第三步：配置AI（可选）

如果不配置AI，小程序会使用本地规则解析时间，支持：
- "30分钟后"
- "2小时后"
- "明天"
- "15:30"

**配置AI后可以获得更强大的识别能力：**

1. 进入小程序"设置"页面
2. 选择AI提供商（Kimi/DeepSeek/智谱GLM）
3. 输入API密钥
4. 点击"测试连接"确认

**获取API密钥：**
- Kimi: https://platform.moonshot.cn
- DeepSeek: https://platform.deepseek.com
- 智谱GLM: https://open.bigmodel.cn

## 第四步：开始使用

### 添加备忘

1. 在首页输入框输入内容，例如：
   - "明天下午3点开会"
   - "30分钟后去取快递"
   - "记住买牛奶"

2. 可以点击相机图标添加图片

3. 点击"保存"按钮

### 查看详情

- 点击任意备忘卡片查看详情
- 可以修改标题、内容、提醒时间
- 可以删除备忘

### 提醒功能

- 到达提醒时间后，打开小程序会看到弹窗提醒
- 如需微信消息通知，需要在设置中配置订阅消息模板ID

## 常见问题

**Q: 数据保存在哪里？**
A: 目前保存在本地，清除缓存或换设备会丢失。

**Q: 图片会丢失吗？**
A: 小程序临时图片路径在重启后可能失效，建议后续版本接入云存储。

**Q: 支持语音输入吗？**
A: 目前不支持，后续版本会添加。

**Q: 可以导出数据吗？**
A: 目前不支持，后续版本会添加。

## 开发者说明

### 技术架构

- 前端：微信小程序原生框架
- 存储：wx.storage 本地存储
- AI：支持多个大模型API

### 主要文件

| 文件 | 说明 |
|------|------|
| `app.js` | 小程序入口，数据存储逻辑 |
| `utils/ai.js` | AI调用工具，支持Kimi/DeepSeek/GLM |
| `pages/index/` | 首页，备忘列表和输入 |
| `pages/detail/` | 详情页，编辑备忘 |
| `pages/settings/` | 设置页，配置AI和订阅消息 |

### 自定义开发

**修改默认AI提供商：**
编辑 `app.js` 中的 `aiConfig.provider`

**修改时间识别规则：**
编辑 `utils/ai.js` 中的 `localParse` 函数

**修改UI样式：**
编辑 `app.wxss` 和各页面的 `.wxss` 文件
